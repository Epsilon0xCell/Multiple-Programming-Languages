Catalogue of specimens, src/ drawer

Multiple-Programming-Languages

A small collection of example programs, one per language, kept as a tour rather than as a single project.

What this is

I keep one short file per language in src/. Each file stands alone. Nothing here builds into one program, and I did not try to make the files agree with each other. The point was to see how the same small jobs look when a different language does them.

Some entries are one screen long. One is a notebook, one is a full assignment document, and one is a query written for a single repo. Where an entry is thin, its label below is thin too. I did not pad a label to make a short file look bigger.

Two entries I have actually run are marked as run. The rest I read closely but did not run, because their toolchains are not installed here and I did not install new tools for this. The labels say which is which.

The specimens

No. 01

Python src/python.pyRun

A tiny time seeded random number generator that prints one number between 0 and 1. It seeds from the current time in whole seconds, so two calls inside the same second return the same value. It only needs numpy. An unused matplotlib import that used to break it on plain machines is gone, and the number it computes is now printed instead of discarded.

No. 02

Go src/Go4Launch.goRead only

A program in package main that prints two launch lines: Go for launch, then Roger that, we are go for launch.

No. 03

Julia src/JuliaGoolia.jlRead only

Prints Fibonacci numbers below 100 by count, up to fib(99). Past fib(93) the 64 bit integers wrap, so the last values print negative even though the loop has not failed.

No. 04

TypeScript src/TypeScript.tsRead only

Prints a greeting, ola amigo, and then a star triangle built row by row. Row i gets i plus 1 stars.

No. 05

C++ src/c-p-p.cppCompiled and run

Prints Hello World! and then a counting loop, the variable i equals 0 through 9. Compiled with g++ in the later pass and run, with that exact output.

No. 06

HTML src/html.htmlRead only

A plain HTML page, the ITcorp example page for Interrupt Technology Corporation, kept as the markup entry in the set.

No. 07

Java src/javajava.javaRead only

A Hello world! program. The class is not marked public, which is what lets it live in a file named javajava.java instead of a file named after the class.

No. 08

Jupyter src/jupyterNotebook.ipynbParsed

A tutorial notebook with markdown cells, a numpy random array cell, and a plotting section. Checked as valid JSON.

No. 09

LaTeX src/latex.texRead only

A university assignment document for ENGE401 using the exam class, with worked solutions. This is the longest file in the drawer and the least like the others.

No. 10

R src/r.rRead only

Estimates pi by Monte Carlo. It draws 100,000 points in a unit square, counts the share inside the quarter circle, and multiplies that share by four.

No. 11

Rust src/rust.rsRead only

A guessing game for a number from 1 to 10. It needs a Cargo project with rand 0.8.3, as its own header says. It will not build with rustc on its own.

No. 12

Solidity src/solidity.solRead only

A contract sketch pinned to Solidity 0.7.1, with hello, helloGas, and balance helpers. The getAccountBalance function is left as an empty exercise stub in the original, and it is still empty here.

No. 13

SQL src/sql.sqlRead only

A ClickHouse style query that estimates contributor longevity from a GitHub events table. The repo name is hardcoded to bitcoin/bitcoin, so it answers for that repo only until that one string is edited.

Honest note

Only the Python and C++ entries were run. The Go, Java, Rust, Julia, R, LaTeX, Solidity, and SQL entries rest on reading the code, not on running it. Their toolchains are not installed in this environment and none was installed. The README states the same limit, and I would rather leave a label short than claim a run that never happened.
