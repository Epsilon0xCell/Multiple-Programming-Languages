The terms of the collection

Every file stands alone. Nothing in src/ imports from a sibling, and each program is complete in its own language, kept side by side so the shapes can be compared.

Some examples were read rather than run, and the bench says which at each frame: their toolchains are absent here, and no new tool was installed to change that. The Python file was run, and the C++ file was compiled with g++ and run.

The Python file seeds from the current time in whole seconds, so two calls inside one second agree. It calls its function once, and says so in its own comments.
